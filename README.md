# 🏦 Bankist — Minimalist Banking Landing Page

**Bankist** is a modern, minimalist banking landing page built to demonstrate advanced **JavaScript DOM manipulation**, UI/UX interaction design, and browser performance optimizations.

[View Live Site](https://nafiulantu.github.io/Bankist-WEB/) *(Replace with your deployment link if hosted on Vercel, Netlify, or GitHub Pages)*

---

## ✨ Features & UI Components

- 📜 **Smooth Navigation Scrolling:** Smooth page navigation using event delegation and `scrollIntoView`.
- 🗂️ **Interactive Tabbed Component:** Dynamic content switching in the Operations section using data attributes and dataset manipulation.
- 📌 **Sticky Navigation Bar:** Implemented using the modern `IntersectionObserver` API for smooth page performance.
- 🖼️ **Lazy Loading Images:** Optimized image loading that swaps low-resolution blurs with crisp images as the user scrolls, boosting initial load speed.
- 🎠 **Testimonial Slider:** Fully custom interactive content/testimonial slider built with JavaScript.
- 🚪 **Modal Window Overlay:** Interactive modal pop-up for account sign-ups with smooth transitions and keyboard (`Esc`) accessibility.
- 💡 **Hover Effects & Transitions:** Fading non-hovered navigation links using event handler binding.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom styles, Flexbox, CSS Grid, animations, and transitions.
- **JavaScript (ES6+):** Advanced DOM manipulation, event delegation, and web browser APIs (`IntersectionObserver`).
